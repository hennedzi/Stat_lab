# Задания по статистике на Python

В данном репозитории приводится пример решения задча по статистике которые изначально предназначались для Statistica.
Решение выполняется в Positrons

Лабораторные работы MSA: выполнение в Positron на Python (аналог Statistica)

Как пользоваться

1. pip install pandas numpy scipy statsmodels matplotlib openpyxl
2. Открывайте нужный labNN_*.py и запускайте ячейки "# %%" по очереди (Ctrl+Enter).
   Каждая ячейка самостоятельна. Над кодом в комментариях - текст задания и путь в меню Statistica.
3. В лабах 13, 14, 15 в ячейках с заданиями укажите свой номер варианта: VARIANT = ...
   Файлы MSA_13/14/15_*.xlsx (данные) уже лежат рядом со скриптами.
4. Графики сохраняются в папку graphs/ (создаётся автоматически).

Состав: лабы 3, 5, 6, 7, 8, 9, 10, 11, 13, 14, 15 (везде, где в методичке есть Statistica).
Лабы 4 и 12 выполняются только в Excel и не включены. Лаба 1 не прикладывалась.

Важно (лаба 10, задания 2 и 3): границы отраслей в таблицах методички не видны (объединённые ячейки);
