# Лабораторные по статистическому анализу данных

В этом проекте задания, которые по методичке выполняются в Statistica, решены на Python. Курс начинается с описательной статистики и сравнения выборок, а дальше переходит к корреляции, регрессии, дисперсионному анализу и проверке распределений.

Код разбит на ячейки `# %%`. В комментариях перед расчётом написано условие, а данные вводятся там, где они нужны по ходу работы. Устанавливать Statistica и Excel не нужно: Python читает исходные таблицы `.xlsx` напрямую.

## Запуск в Positron

1. Установите Positron и `uv`. Затем откройте в Positron папку с `pyproject.toml` через **File → Open Folder**.
2. В меню **Terminal → New Terminal** откройте терминал и выполните:

   ```bash
   uv sync
   ```

   Версия Python и минимальные версии библиотек заданы в `pyproject.toml`. Если установка остановится, посмотрите, какую версию `uv` не смог подобрать. Пока зависимости не установились, переходить к запуску ячеек нет смысла.

3. Выберите интерпретатор из `.venv` и запустите Python-сессию. Если Positron уже открыл сессию с другим Python, переключитесь на окружение проекта. Проверить текущий интерпретатор можно в **Console**:

   ```python
   import sys
   print(sys.executable)
   ```

   В пути должна быть папка `.venv`.

4. Откройте нужный скрипт и нажмите **Run Cell** над блоком `# %%`. Если в задании есть `VARIANT = 1`, подставьте свой номер и запустите ячейку целиком.

Числа и таблицы появляются в **Console**, графики — в **Plots**. PNG сохраняются в `graphs/`. Если не найден файл `.xlsx`, проверьте рабочую папку в консоли:

```python
from pathlib import Path

print(Path.cwd())
```

Если скрипт читает таблицу по имени без указания папки, файл должен лежать именно в этой рабочей папке.

## Как читать вывод

Цифры отвечают на разные вопросы. `p` нужен для решения по гипотезе, а разность средних, долей или коэффициент — чтобы понять направление и величину эффекта. При пороге `α = 0,05` результат с `p < 0,05` считают статистически значимым. Если `p ≥ 0,05`, пишите «статистически значимого различия не обнаружено», а не «выборки одинаковы». Значение `p` не показывает вероятность того, что гипотеза верна.

### Описательная статистика

`N` — число наблюдений, `Mean` — среднее, `SD` — разброс отдельных значений вокруг среднего, `SE` — стандартная ошибка среднего. Не путайте `±SD` и `±SE` на графике: первое описывает разброс данных, второе — неопределённость оценки среднего. `95% ДИ` — доверительный интервал для оцениваемого параметра, а не диапазон, в который попадают 95% наблюдений.

### Сравнение выборок

Если в выводе есть и `F`, и `t`, у них разные задачи. В этой работе по `p` F-теста выбирают вариант t-теста: Стьюдента с общей оценкой дисперсии, если различие дисперсий не обнаружено, или Уэлча, если обнаружено. На вопрос «различаются ли средние?» отвечает `p` из t-теста. Чтобы понять, какая группа выше и на сколько, сравните сами средние.

Для измерений «до/после» парный t-тест работает с разностями внутри пар. Если в задании спрашивают именно о росте, смотрите строку одностороннего теста с альтернативой «после > до». В тесте одной выборки среднее сравнивается с заданным значением. При сравнении долей смотрите обе доли, разность в процентных пунктах и `p` z-теста: 29% против 21% — это 8 процентных пунктов.

Манна–Уитни и Вилкоксон работают с рангами. Первый применяется к независимым группам, второй в этих работах — к парным измерениям. Их результат не стоит описывать как проверку равенства средних.

### Корреляция и регрессия

У коэффициента корреляции знак показывает направление связи, а модуль — её выраженность. Пирсон оценивает линейную связь, Спирмен — тенденцию к росту или снижению по рангам. Частная корреляция показывает связь после учёта остальных переменных. По одной корреляции причинность не устанавливают.

В регрессии `p` общего F-теста относится к линейной модели в целом, а `p` напротив коэффициента — к конкретной переменной. Коэффициент `−2` означает, что при увеличении этой переменной на единицу модель предсказывает снижение результата на 2 единицы при фиксированных остальных переменных. `R² = 0,54` означает, что модель объясняет 54% разброса на этих данных, но ничего не гарантирует для новых данных. В выводе прогноза различайте интервал для среднего ответа и более широкий интервал для отдельного наблюдения.

### Дисперсионный анализ и распределения

В таблице ANOVA смотрите `p` в строке нужного фактора. Значимый общий тест не показывает, какие именно группы различаются: для этого нужны попарные сравнения. Если значимо взаимодействие, сравнивайте группы отдельно на разных уровнях второго фактора. Результаты Fisher LSD читайте с осторожностью: в этих сравнениях нет поправки на множественность.

В проверке согласия по χ² сравниваются наблюдаемые и ожидаемые частоты. Малое `p` даёт основание отвергнуть проверяемый закон; большое `p` не доказывает, что этот закон верен. В двухвыборочном тесте Колмогорова–Смирнова `D` — максимальный разрыв между эмпирическими функциями распределения. Если тест значим, это говорит о различии распределений, но не обязательно о различии средних.

### Графики

У гистограмм двух групп сравнивайте форму при одинаковых границах интервалов. На диаграмме размаха линия внутри ящика — медиана, ящик охватывает центральные 50% наблюдений, а точки за усами не обязательно являются ошибками. На графике «до/после» одна линия соединяет два измерения одного объекта. По рисунку удобно увидеть направление изменений, а вывод о значимости берите из теста.
