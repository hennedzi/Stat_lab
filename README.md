# Статистический анализ данных на Python

Лабораторные работы по курсу статистического анализа данных. В методичках расчёты выполняются в программе **Statistica**. Здесь те же задания решены на **Python** в среде **Positron**, чтобы не зависеть от платного ПО.

## Что это за проект

- Каждая лабораторная работа — отдельный скрипт.
- В начале каждой ячейки в комментариях написан текст задания и путь в меню Statistica, который заменяет этот код.
- Код идёт по шагам, в том же порядке, что и в методичке: ввод данных, расчёт, вывод, график.
- Результаты печатаются в консоль, графики показываются на панели Plots и сохраняются в папку `graphs/`.

## Что за предмет

Предмет посвящён прикладной статистике: как по выборке сделать обоснованный вывод.

В лабораторных разбираются:
- описательная статистика, таблицы частот, гистограммы;
- сравнение выборок (критерии Фишера, Стьюдента) и проверка гипотез о среднем и о частотах;
- корреляционный и регрессионный анализ (парный, частный, множественный, нелинейный, пошаговый);
- дисперсионный анализ (однофакторный, многофакторный, с повторными измерениями);
- непараметрические критерии (Манна-Уитни, Вилкоксона, Спирмена);
- критерий «хи-квадрат» и критерий Колмогорова-Смирнова для проверки законов распределения.

Во всех лабораторных выводы делаются при уровне значимости 0,05.

## Что нужно установить

1. **Positron** (бесплатная среда для данных от Posit) — https://positron.posit.co/
2. **Python** нужной версии. Версия указана в `pyproject.toml` (`requires-python`).
3. **uv** (менеджер окружений, рекомендуется) или обычный `pip` с `venv`.
4. Библиотеки из `pyproject.toml`:
   - `numpy`, `pandas`, `scipy`, `statsmodels` — вычисления и статистика;
   - `matplotlib`, `seaborn` — графики;
   - `openpyxl` — чтение данных из Excel-файлов.

## Настройка в Positron

1. **Откройте папку проекта целиком:** File → Open Folder. Не открывайте отдельный скрипт без папки: пути к данным и папке `graphs/` считаются от рабочей папки.
2. **Создайте окружение и поставьте библиотеки.** Откройте терминал в Positron (Terminal → New Terminal) и выполните одно из двух.

   Вариант с uv (по `pyproject.toml`):
   ```bash
   uv sync
   ```

   Вариант с обычным Python:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS / Linux:
   source .venv/bin/activate
   pip install matplotlib numpy openpyxl pandas scipy seaborn statsmodels
   ```
3. **Выберите интерпретатор:** справа вверху (или Ctrl+Shift+P → Python: Select Interpreter) выберите Python из `.venv`.
4. **Запустите консоль** кнопкой Start Session. Название выбранного окружения должно появиться в правом верхнем углу.
5. **Положите данные рядом со скриптами.** Файлы Excel с данными заданий должны лежать в корне проекта, рядом со скриптами.

## Как запускать

- Скрипт разбит на ячейки строками `# %%`. Поставьте курсор в ячейку и нажмите **Ctrl+Enter** (на macOS Cmd+Enter). Над ячейкой также есть кнопка Run Cell.
- Каждая ячейка самостоятельна: свои импорты и данные, поэтому любую можно запускать отдельно и в любом порядке.
- Весь файл целиком запускает кнопка Run File.
- Результаты смотрите в Console, графики — на панели Plots. Копии графиков сохраняются в `graphs/` автоматически.
- Если ячейка меняла данные, перезапустите её целиком, а не отдельные строки.

## Варианты заданий

В лабораторных, где данные берутся из Excel по номеру варианта, в нужной ячейке есть строка:

```python
VARIANT = 1   # <-- укажите свой номер
```

Измените число на свой вариант и запустите ячейку заново. Допустимый диапазон написан в комментариях к ячейке.

## Как читать результаты

- **p < 0,05** — различие или связь статистически значимы.
- **p ≥ 0,05** — значимых оснований считать различие или связь существенными нет. Это не доказывает, что различия не существует.
- При сравнении независимых выборок сначала проверяется равенство дисперсий (F-критерий). Дальше берётся t-критерий Стьюдента при равных дисперсиях или вариант с раздельными оценками при разных.
- Числа могут слегка отличаться от Statistica: разные алгоритмы подбора интервалов в «хи-квадрат», разный метод оценки в нелинейных моделях, разные приближённые post-hoc критерии.

## Если что-то не работает

- **`FileNotFoundError` на Excel-файле.** Откройте папку проекта целиком (шаг 1), положите файл в корень и перезапустите консоль.
- **`ModuleNotFoundError`.** Не выбран интерпретатор из `.venv` или библиотеки не установлены (шаг 2 и 3).
- **Не устанавливаются версии из `pyproject.toml`.** Если какой-то версии нет в индексе или она несовместима, ослабьте ограничения (например, замените `>=3.11.2` на `>=3.9`) и выполните `uv sync` заново. Скрипты написаны на стандартных функциях и обычно работают на нескольких версиях библиотек.
- **Графики не отображаются.** Проверьте панель Plots. Сохранённые копии лежат в папке `graphs/`.
- **Кракозябры вместо русских букв на графиках.** Установите в системе шрифт с кириллицей (например, DejaVu Sans) или перезапустите консоль.
